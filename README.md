## How to Run
### HTML practice
Open `html-practice/index.html` in a browser.

### React app
1. Install Node.js.
2. Open a terminal in the project folder.
3. Run:
   ```bash
   cd react-app
   npm install
   npm run dev
   ```
4. Open the local URL shown in the terminal.
